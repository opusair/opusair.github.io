Multi-Head Latent Control: A Unified Interface for LLM Agent Decision Making

2026-07-15T00:00:00.000Z

Researchers introduced Multi-Head Latent Control, a lightweight layer that reads hidden-state trajectories from frozen LLMs or VLMs to generate deployment-time control signals. By utilizing a Capability Head to predict if the model should defer tasks, and a Resolution Head to handle routing decisions (clarification, tool use, abstention, or answering), the method operates entirely post hoc without updating backbone weights.
